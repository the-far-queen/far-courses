# Interrogative Planning

**How to use:** paste at the start of a project. Tell the model: "Run Interrogative Planning. Do not generate the artifact until Gate 3 is signed."

## The 4 gates

Gate 1 (Domain): 5-10 questions about audience, constraint, genre, anti-artifact, precedent.
Gate 2 (Substrate): 5 questions about axiom, witness, falsification, medium, platform.
Gate 3 (Sign-off): the signed spec. No artifact generation until signed.
Gate 4 (Validation): schema + gate + witness + falsification check.
