## The 4-stage pipeline

Stage 1: compile (course + exam + question from canonical axes)
Stage 2: gate (1-bit veto per artifact type)
Stage 3: format (Amazon ebook, X Article, Substack, TikTok teaser)
Stage 4: witness + publish (SHA-256 fingerprint per artifact)
